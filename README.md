## 📌 Sobre o Projeto

Este projeto é uma **landing page completa e profissional** desenvolvida para uma corretora imobiliária. A aplicação serve como uma vitrine digital para apresentação de lançamentos, imóveis disponíveis e detalhes de propriedades, otimizando o processo de captação de potenciais clientes (*leads*).

O site possui navegação intuitiva, layout totalmente responsivo e páginas dedicadas para visualização detalhada de imóveis.

🔗 **Acesse o projeto online:** [gabrielbrandaof.github.io/Corretora_LP](https://gabrielbrandaof.github.io/Corretora_LP)

---

## 🚀 Funcionalidades

- **Apresentação de Lançamentos:** Destaque para empreendimentos e novos imóveis.
- **Página de Detalhes do Imóvel (`imovel.html`):** Estrutura dedicada para exibir fotos, especificações e diferenciais de cada propriedade.
- **Design Responsivo:** Otimização para visualização em dispositivos móveis, tablets e computadores.
- **Refatoração & Manutenibilidade:** Código organizado e padronizado para facilitar atualizações futuras.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica e suporte a múltiplas páginas.
- **CSS3:** Estilização moderna, recursos visuais e responsividade.
- **JavaScript:** Lógica de navegação, dinâmica e interatividade.
- **GitHub Pages:** Hospedagem e deploy automatizado.
